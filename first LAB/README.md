# a short description

This dataset shows the history of console gaming. It shows how many units each console sold until now, and many other info to help us compare between the compines and their performance through the generations.

# Console_Data.csv info:

1- Console Name: The market name for the console released
2- Type: In this dataset all the consoles are "Home", but look into the scrape repository if you want to get data on Handheld consoles as well
3- Company: Company responsible for the release of the console (Nintendo, Sony, etc)
4- Gen: Of which generation of consoles is the console a part of
5- Gen Years: Used for my tableau visual, indicates the period in which each generation takes place
6- Release Year/Discontinuation Year: Indicates the period of sales for the console
7- Units Sold (million): How many units of the console were sold
8- Remarks: Some additional info on the console
